## ✦ Development

### Clone a repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
```

### Install dependencies

```bash
npm install
```

### Start development

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

> Refer to the README of each repository for project-specific setup, environment variables, services, and deployment instructions.
